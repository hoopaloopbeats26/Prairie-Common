# Locked decisions

1. Prairie Common is a long-term Prairie hip-hop physical-media archive.
2. Public site remains minimalist/classy and text-forward.
3. Homepage slogan/layout already approved; do not rewrite by default.
4. Exact attribution: “Prairie Common is managed by Trendkill Productions.”
5. Use actual Prairie Common logo/identity only.
6. Navigation/data model: Artists (not People); Labels includes collectives; aliases are captured; every name is linkable where documented.
7. Release records use PC-REL identifiers and preserve physical format/variant distinctions.
8. Gallery ordering follows the archive’s approved object/release sequencing, not arbitrary upload order.
9. Map supports item-level dots and filtering; unconfirmed data remains separate from All.
10. Public factual claims require dependable evidence; research leads remain private/unconfirmed until supported.
